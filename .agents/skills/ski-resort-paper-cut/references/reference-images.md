# 作風の参照画像

Snowcationに採用済みの画像を直接参照する。以下のパスはリポジトリルート基準である。作例は写真・コース図に代わる事実の根拠にはしない。実在施設の形と配置は新しい制作のたびに調べる。

| ファイル                          | 用途                                                                       | 引き継がないもの                                                 |
| --------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `src/assets/grandeco.webp`        | 基本の作風。紙の素材、青と白の雪景色、暖色の光、木々の重なりと遠くの山の面 | 別施設を描くときのゴンドラ、ホテル、地形そのもの                 |
| `src/assets/nekoma-mountain.webp` | 横に広がるホテル、複数の斜面、木々のまとまりの例                           | 正確なリフト路線・終点の根拠や、別の画像を編集するときの対象画像 |
| `src/assets/tazawako.webp`        | 斜面から湖を見下ろす視点の例                                               | 他施設に湖を追加する理由、遠景の細部を常に同じ密度で描く指定     |

画像を実際に開き、今回に必要な作例だけを画像生成ツールへ渡す。ユーザーが今回指定した新しい作例があれば、そちらを優先する。参照画像が取得できない環境ではSKILL.mdの作風記述で進められる。

2026-10-26に上記3枚を目視し、いずれも横長3:2であることを確認した。ファイルが差し替わる場合は、現在の内容・縦横比をあらためて確認する。遠景の単純化には、同日の「グランデコのように、遠くの山は面にしてもいい」という追加指定を反映している。
