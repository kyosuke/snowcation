秋田駒ヶ岳の中腹に広がる、東北を代表するスノーリゾート。深さ日本一を誇るコバルトブルーの田沢湖を眼下に望みながら滑ることができる、景観も抜群のゲレンデ。

- **パウダースノー**: 上質な積雪量を誇り、非圧雪コースも40%と多め。コブや深雪を楽しめる
- **コースバリエーション**: 初級から上級まで全13コース。上級者向けの急斜面も充実
- **ロングクルーズ**: 白樺・国体コースは1,600mのロングコース。田沢湖の絶景を見ながら滑れる
- **アクセス**: 田沢湖駅からバス約30分と、東北新幹線との接続も良好

## [亀の井ホテル 田沢湖](https://kamenoi-hotels.com/tazawako/)

田沢湖高原温泉に位置するホテル。スキー場への無料送迎があり、2種の天然温泉でスキー後のリラックスも充実。田沢湖駅からも無料シャトルバスで利用できる。

### チェックイン・チェックアウト

- **チェックイン**: 15:00
- **チェックアウト**: 10:00

### ワーケーション環境

- **WiFi**: 館内全体で無料WiFiが利用可能

### ゲレンデへの移動

ホテルからスキー場へは、ホテル送迎バスと路線バスの2種類が利用できる。

```d2
direction: right

Hotel: 亀の井ホテル田沢湖 {shape: circle}
SkiArea: たざわ湖スキー場 {shape: circle}

Hotel -> SkiArea: "ホテル送迎バス (冬期のみ)\n8:00 / 9:00発 (要予約)" {
  style: {
    stroke-dash: 2
    italic: false
  }
}
SkiArea -> Hotel: "ホテル送迎バス (冬期のみ)\n16:10発 (要予約)" {
  style: {
    stroke-dash: 2
    italic: false
  }
}
Hotel <- SkiArea: "羽後交通バス\n約8分" {
  style: {
    stroke-dash: 4
    italic: false
  }
}
```
